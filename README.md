# FP&A Hub

A personal public hub for FP&A learning projects, finance automation experiments, reference material, and reusable ideas.

## Intended scope

- forecasting and planning concepts;
- finance automation experiments;
- metric and variance analysis;
- scenario modelling ideas;
- reporting and visualization patterns;
- AI-assisted FP&A workflows;
- links to related public finance projects as they mature.

## Project context

This is a personal, self-directed learning project by João Caldas. I learn by building, comparing approaches, documenting what works, and turning useful patterns into reusable components.

AI tools are used extensively during research, design, coding, debugging, testing, and documentation. AI output is treated as input to review rather than proof of correctness. Public examples must use synthetic, public, or appropriately licensed data and must not expose employer, client, family, or other private information.

## Direction

FP&A Hub should become the navigation and knowledge surface for the public finance portfolio rather than duplicating application code from every finance project.

Related implementation projects currently include:

- `fp-a-metric-monitor`
- `fpa-monitor-app`
- `fpa-trends-web`

## Status

Lab / portfolio hub under active development.
